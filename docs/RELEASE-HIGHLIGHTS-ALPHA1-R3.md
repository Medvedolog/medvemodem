# MedveModem 0.16.0 Alpha 1 r3 — highlights

**Prerelease · OpenWrt 24.10.8 (IPK) / 25.12.6 (APK)**

## Основные изменения / Highlights

- **Обновлена страница LuCI «Белые списки»:** компактная сводка каналов с состоянием, названием модема, оператором и временем последней проверки.
- **Матрица проверок сайтов:** фильтры по доступности, ошибкам DNS и TLS; закреплённые названия сервисов; время проверки для каналов.
- **История ограничений:** события `limited`, `ok`, `down` из уже существующего журнала движка и длительность завершённых периодов ограничения.
- **Уведомления:** статус SMS-отправки и тестовое SMS на странице; Telegram настраивается отдельно в боте.
- **Адаптивная вёрстка:** компактная мобильная компоновка, дополнительная конфигурация в свёрнутом блоке.
- **Документация:** переработанное руководство по диагностике доступа только к доменам белого списка оператора.
- **Пакеты обновлены до `0.16.0_alpha1-r3`** для движка, LuCI, бота и LuCI бота.

### Packaging / Сборки

- Шесть наборов пакетов: `aarch64_cortex-a53`, `aarch64_generic`, `x86_64` × OpenWrt `24.10.8` / `25.12.6`.
- В каждом архиве: MedveModem, LuCI, Telegram-бот, LuCI бота и опциональный lpac.
- Отдельные файлы `SHA256SUMS` и `HIGHLIGHTS.txt`.
- Установщик QModem использует постоянный релиз `qmodem-3.3.0_p20261108-r1`.

**Ограничения:** сборка SDK не заменяет тестирование на физическом роутере. Автоматического переключения физических SIM-слотов не добавлено.
