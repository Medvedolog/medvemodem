# MedveModem — установка и обновление

**Срез документации:** публичная `0.16.0-alpha1-r1`, переименована из `0.15.0-r197` 16.11.2026. Проект в состоянии альфы; наличие исходников **не означает**, что стендовая сборка этой версии опубликована. Проверяйте текущее состояние и [Releases](https://github.com/Medvedolog/medvemodem/releases).

Перед установкой обеспечьте резервный доступ к роутеру: Ethernet, Wi-Fi или локальную консоль, не зависящие от испытываемого модема. Не устанавливайте одновременно другой управляющий менеджер того же модема.

## 1. Выбор пакетов

На роутере:

```sh
. /etc/openwrt_release
echo "OpenWrt: $DISTRIB_RELEASE; архитектура пакетов: $DISTRIB_ARCH"
df -h /overlay
```

На странице нужной **стендовой сборки**, а не в исходном ZIP, выберите точное совпадение архитектуры и линии OpenWrt. Основной архив обычно называется `medvemodem-<версия>-<архитектура>-<линия>.tar.gz` и содержит движок, LuCI, пакеты lpac. Отдельно могут быть `medvemodem-bot-<версия>-<линия>.tar.gz` и пакет QModem. На 25.12/snapshot используются APK, на 24.10 — IPK. Не путайте архитектуру процессора с `DISTRIB_ARCH` из установленной прошивки.

Движок статически включает libubox/libubus/libuci, но **остальные зависимости** (например, ModemManager, qmi-utils, jsonfilter, libjson-c) устанавливает пакетный менеджер из подходящих репозиториев. Не заявляйте совместимость со всяким snapshot без проверки пакетов.

## 2. Установка основного пакета

Передайте **один выбранный** архив, указав настоящее имя скачанного файла:

```sh
# На компьютере, в каталоге со скачанным архивом:
scp ./имя_скачанного_архива.tar.gz root@192.168.1.1:/tmp/
```

На роутере:

```sh
mkdir -p /tmp/medvemodem-install
cd /tmp/medvemodem-install
# Замените имя файла на название переданного архива:
tar -xzf /tmp/имя_скачанного_архива.tar.gz
ls -l *.apk *.ipk 2>/dev/null
```

Выберите **один** вариант для своей системы:

```sh
# OpenWrt 25.12 / apk:
apk update
apk add --allow-untrusted ./medvemodem-0*.apk ./luci-app-medvemodem-*.apk

# ИЛИ OpenWrt 24.10 / opkg:
opkg update
opkg install ./medvemodem_*.ipk ./luci-app-medvemodem_*.ipk
```

Не запускайте оба блока подряд и не ставьте по маске всё из каталога: дополнительные пакеты могут включать опциональные транспорты eSIM. Движок и LuCI должны быть **одной версии**. Если пакетный менеджер сообщает об ошибке, остановитесь и сохраните текст ошибки.

## 3. Дополнительные компоненты

**Из LuCI, без SSH.** После установки движка зайдите в «Модем» → «MedveModem» → «Настройки» → «Диагностика и
компоненты». Карточка «Драйверы и ModemManager» показывает, что из нужного модемам уже стоит, и ставит недостающее
кнопкой из лент самого роутера: ModemManager, драйверы ядра (`option`, `qmi_wwan`, `cdc_mbim`, `cdc_ncm`, `cdc_ether`,
`rndis_host` и другие), `umbim` и `uqmi` для прямого подключения, `usb-modeswitch`, `qmi-utils`. Сначала идёт пробный
прогон: если чего-то нет в лентах (модули ядра снапшота, отключённая лента), ничего не ставится, а журнал говорит, чего
не хватило. Работающий ModemManager при этом не перезапускается. Там же карточка «QModem» ставит ядро QModem из
архива стендовой сборки. Те же действия можно сделать и вручную по SSH (`apk add …` / `opkg install …`).

Telegram-бот ставится из **отдельного** архива вместе с `luci-app-medvemodem-bot` (версии должны соответствовать движку). eSIM в этой ревизии работает **только на чтение**; компоненты `medvemodem-lpac`/дополнительные APDU-драйверы устанавливаются по требуемому транспорту. QModem ставится отдельно при выбранном способе управления или из интерфейса компонентов. Не заменяйте системный `lpac` случайным пакетом другого проекта.

## 4. Проверка и обновление

```sh
/etc/init.d/medvemodemd status
ubus call medvemodem status
logread -e medvemodem
```

LuCI: «Модем» → «MedveModem». После изменения файлов LuCI при необходимости перезапустите `rpcd` и обновите вкладку браузера; установка пакета LuCI выполняет это в `postinst` и может завершить текущую веб-сессию.

Обновление — тем же способом, но новым согласованным набором пакетов. Настройки обычно сохраняются, однако восстановление сети через модем во время перезапуска демона **может занять время**. Перед обновлением сохраните `/etc/config/medvemodem` и убедитесь в наличии резервного доступа.

Удаление: `apk del luci-app-medvemodem medvemodem` либо `opkg remove luci-app-medvemodem medvemodem`. Не удаляйте другие установленные менеджеры и сетевые интерфейсы автоматически.

Автоматическое восстановление можно отключить отдельно:

```sh
uci set medvemodem.core.auto_recovery='0'
uci commit medvemodem
/etc/init.d/medvemodemd restart
```

## 5. Если модем не появился

Соберите `medvemodem diag quick`, вывод `ubus call medvemodem status`, `logread -e medvemodem`, `logread -e ModemManager` и точную версию прошивки. Не публикуйте неотредактированные журналы с идентификаторами SIM или паролями. Для полевой диагностики — BENCH и [база модемов](modem-zoo/README.md).
