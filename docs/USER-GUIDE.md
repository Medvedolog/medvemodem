# MedveModem: краткая инструкция по эксплуатации

Памятка для линии исходников **0.15.0-r197** (16.11.2026). Подробности — [MANUAL](MANUAL.md),
установка — [INSTALL](INSTALL.md), текущее состояние и ограничения — STATUS,
API — [UBUS-API](UBUS-API.md). Содержание памятки не заменяет проверки на конкретном модеме.

## 1. Что это

MedveModem — служба OpenWrt (24.10 и 25.12), которая находит USB-модемы, решает, кто ими управляет, держит
подключение, проверяет интернет, переключает канал при сбое и сама чинит модем по ступеням восстановления. Поверх
неё работают три интерфейса: веб (LuCI), консоль (CLI и TUI) и Telegram-бот. Все три читают одно и то же из движка.

## 2. Установка и обновление

Пакеты из стендовой сборки `bench-v<версия>-<коммит>` (GitHub → Releases), архив под свою архитектуру и линию OpenWrt:
`…-25.12.x`/snapshot (apk) и `…-24.10.x` (opkg); обязательно сверяйте точное имя и цель архива в опубликованной сборке. Архитектура:
`aarch64_cortex-a53` (OPi Zero 3, Filogic, Airoha AN7581 — Nokia XG-040G-MD), `aarch64_generic` (Rockchip, RPi 64),
`x86_64`. Подробно: [INSTALL.md](INSTALL.md).

```sh
# 25.12 и снапшот (apk)
apk update
apk add --allow-untrusted ./medvemodem-0*.apk ./luci-app-medvemodem-*.apk
# 24.10 (opkg)
opkg update
opkg install ./medvemodem_*.ipk ./luci-app-medvemodem_*.ipk
```

`medvemodem-lpac*` из того же архива — только для eSIM. ModemManager, драйверы модемов, umbim/uqmi, usb-modeswitch,
QModem и lpac ставятся и из LuCI: «Настройки» → «Диагностика и компоненты», кнопками с журналом (lpac — наша сборка из
выпуска MedveModem на GitHub, с проверкой SHA256).

После обновления:

```sh
/etc/init.d/medvemodemd restart       # движок; интернет через модемы не пропадает
/etc/init.d/medvemodem-bot restart    # бот
/etc/init.d/rpcd restart              # LuCI видит новые методы
rm -rf /tmp/luci-indexcache /tmp/luci-modulecache
ubus call medvemodem status | grep version
```

Затем Ctrl+F5 в браузере. Сеть и Wi-Fi целиком не перезапускаются никогда: MedveModem трогает только свои интерфейсы.

## 3. Веб-интерфейс (LuCI): «Модем → MedveModem»

### «Модемы» (главная)
- Плашка вверху: работает ли интернет, через какой канал, какие резервы по порядку. Раскрывается в таблицу каналов:
  №, канал, устройство, статус, метрика, трафик за сегодня, проверка, почему так.
- Карточки модемов (или таблица, переключатель «Карточки / Таблица»): оператор, сигнал, роль (основной / резерв),
  трафик, проверка интернета («Интернет · 57 мс»; серое «Данные устарели» — старый результат).
- Меню модема: «Сделать основным», «Пауза», «Заморозить» (никто — ни MedveModem, ни QModem, ни ModemManager — его не
  трогает).
- «Порты и устройства»: дерево USB, журнал подключений, имена портов.
- Уровень «Базовый / Подробный» (справа вверху) прячет или показывает инженерные подробности; «Скрыть
  идентификаторы» — для скриншотов (IMEI, ICCID, номера, адреса, ссылка на карту).

### Страница модема (из карточки)
- **Обзор** — состояние, подключение, SIM, проверка интернета, «Проверить соединение».
- **Сеть и сигнал** — технология, диапазоны, агрегация несущих (частоты канала ↓/↑, PCI, уровни каждой несущей),
  вышка на карте, расстояние по TA, история сигнала, антенны, соседние соты с кнопкой «Закрепить» (где модем это
  умеет), «Режим сети и диапазоны» с «Изменить»; любое изменение откатывается само, если интернет не вернулся.
- **SMS** — переписки, отправка, записная книжка (до 20 контактов, импорт `.vcf`), USSD с кнопками кодов оператора,
  AT-консоль с готовыми командами (где AT-порт у движка). Когда память модема заполняется на три четверти, старые
  входящие переезжают в роутер (последние 500).
- **Настройки** — APN, тип IP, DNS, фиксация TTL 64, автоподключение, AT-порт, «Найти AT-порт».
- **Диагностика** — ступени восстановления (см. §6), журнал модема, отчёт о модеме для разработчика.

### «Настройки»
Вкладки: «Состояние службы», «Интернет и резерв» (приоритет каналов, автопереключение, проверки), «Модемы» (кто
управляет по умолчанию, драйверы, ModemManager, QModem), «Уведомления», «Диагностика и компоненты».

### «Telegram-бот»
«Обзор» (всё ли работает), «Мастер настройки» (токен → администратор по Telegram ID → проверочное сообщение),
«Настройки». Бот: кнопки «Статус», «Модемы», «Каналы», «Лимиты», «Журнал», «Справка»; команды `/menu`, `/status`,
`/modems`, `/uplinks`, `/quota`, `/events`, `/help`. Входящие SMS пересылает в чат. Сообщает об одной ситуации одним
сообщением; после перезапуска службы 2 минуты молчит и шлёт одну тихую сводку.

### Веб модема в режиме роутера (HiLink, ZTE)
На главной у такого модема ссылка на его веб через порт роутера (`192.168.1.1:808x`): посредник
`medvemodem-webproxy` подставляет модему его собственный адрес, так что страница открывается и с ПК, где прокси-клиент
уводит `192.168.8.1` в туннель.

## 4. Консоль: `medvemodem`

`<id>` — идентификатор модема из `medvemodem list` (`usb-serial:…` или `usb-port:…`).

| Команда | Что делает |
|---|---|
| `medvemodem tui` (или `top`) | экран как в LuCI, см. §5 |
| `medvemodem list` | модемы: id, модель, владелец, интерфейс |
| `medvemodem show <id>` | всё о модеме (JSON) |
| `medvemodem status` / `uplink` / `channels` | состояние службы / интернет и каналы / все каналы роутера |
| `medvemodem events <id> --text` | журнал модема |
| `medvemodem rescan` | пересканировать USB |
| `medvemodem metrics <id>` | сигнал |
| `medvemodem at <id> 'AT+CSQ'` | AT-команда через порт движка (по очереди с остальными) |
| `medvemodem sms <id>` / `sms send <id> <номер> <текст>` / `sms delete <id> <n>` | SMS |
| `medvemodem ussd <id> '*100#'` / `ussd reply` / `ussd cancel` | USSD |
| `medvemodem recover <id> <ступень>` | ступень восстановления (§6) |
| `medvemodem bringup <id>` / `hangup <id>` / `dial <id> --apn …` | поднять / опустить подключение |
| `medvemodem freeze <id> on\|off` | заморозить модем |
| `medvemodem config plan\|apply\|rollback <id>` | настройка интерфейса модема с откатом |
| `medvemodem diag quick` / `diag profile <id> --at` | быстрый отчёт / отчёт о модеме |
| `medvemodem dns-check <netdev>` | проверка подмены DNS у оператора |
| `medvemodem probe <id>` | поиск AT-порта |
| `medvemodem esim status <id>` | eSIM |

Всё это же доступно через ubus: `ubus call medvemodem <метод> '{…}'` (`docs/UBUS-API.md`).

## 5. TUI: `medvemodem tui`

Список модемов → экран модема с вкладками «Обзор», «Радио», «Сервис».

| Клавиша | Действие |
|---|---|
| `j` / `k`, стрелки | вниз / вверх |
| `Enter`, `l` | открыть |
| `h`, `b`, `Esc`, Backspace | назад |
| `Tab`, `1`–`9` | вкладка / пункт |
| `r` | обновить |
| `q`, Ctrl+C | выход |

Ключи: `--once` (один снимок без интерактива), `--lang ru`, `--ascii`, `--no-color`, `--width N`,
`--show-identifiers`.

## 6. Восстановление: ступени

От мягкой к жёсткой; движок проходит их сам и останавливается на первой, после которой интернет вернулся. Сам
он делает ступени 1–3 у любого модема, а 4, 5 и 7 — у модели, профиль которой их объявляет; 6 и 8 только вручную:

1. `observe` — проверка, ничего не трогает;
2. `session` — переподключение сессии;
3. `control` — перезапуск управления (ModemManager / QModem / свой);
4. `radio` — радио выключить и включить (повторный поиск сети);
5. `soft-reset` — перезагрузка модема командой;
6. `rebind` — перепривязка драйвера;
7. `usb-reset` — переподключение USB;
8. `power` — питание порта (где плата умеет).

Вручную: «Диагностика» на странице модема или `medvemodem recover <id> <ступень>`. Автоматическое восстановление
выключается `uci set medvemodem.core.auto_recovery=0; uci commit medvemodem; /etc/init.d/medvemodemd restart`.

## 7. Архитектура

```
 LuCI · CLI/TUI · Telegram-бот          ← клиенты, только через ubus
            │
     ubus-объект «medvemodem»            ← единый API
            │
     medvemodemd (C, один процесс, uloop)
       ядро: реестр устройств, владение, подключения, AT-аренда,
             проверка интернета, автопереключение, DNS, восстановление
       модули mgr_*: SMS, радио, eSIM, веб модема, сигнал, лимиты,
             USB-дерево, SIM, история AT
       отдельные процессы: AT-задания, воркер mmcli, пересылка SMS,
             eSIM (lpac), помощники TTL/маршрутов/веба
            │
 исполнители (у одного модема — ровно один):
   свой (AT + QMI/MBIM/ECM через netifd) · ModemManager · QModem · веб модема (HiLink/ZTE)
```

**Принципы:**
- **Один владелец модема.** У каждого модема один хозяин: движок, ModemManager или QModem. Остальные к нему не
  прикасаются. У Foxconn T99/T77 ModemManager получает только управляющий порт, AT-порты остаются у движка.
- **Опознавание.** Модем узнаётся по серийному номеру USB, без него — по порту USB. Имя и настройки следуют за
  модемом в другой порт по хэшу IMEI (сам IMEI не хранится). Версия прошивки в опознавание не входит.
- **Поколения подключения.** После переподключения USB старые результаты отбрасываются: `ttyUSB2` после переподключения —
  не обязательно тот же модем.
- **Аренда AT-порта.** Все AT-запросы (SMS, USSD, сигнал, консоль) идут по очереди через движок; никто не открывает
  tty сам.
- **Транзакции с откатом.** Смена режима сети, диапазонов, привязки к соте, настроек интерфейса: если интернет
  через модем не вернулся, прежнее возвращается само.
- **Профили** (`/usr/share/medvemodem/profiles`, 80+ моделей): кто лучше управляет моделью, AT-диалект, порты,
  особенности (например, «USSD в LTE уводит модем в 3G»), безопасные ступени восстановления.

**Где что лежит:**
- `/etc/config/medvemodem`, `/etc/config/medvemodem-bot` — настройки (меняются из LuCI);
- `/etc/medvemodem/` — состояние на флеше (архив SMS, история);
- `/var/run/medvemodem/` — оперативное состояние;
- `logread -e medvemodem` — журнал.

## 8. Частые вопросы

- **Нет вкладки AT у модема.** Его AT-порт занял ModemManager или QModem: «Настройки» модема → «AT-порт» покажет кто.
  У T77/T99 с r104 правило для ModemManager пишется само; действует после перезапуска ModemManager
  (`/etc/init.d/modemmanager restart`, связь через его модемы пропадёт примерно на минуту).
- **USSD рвёт интернет.** Некоторые модемы в LTE уходят на время запроса в 3G (T99, T77): страница спрашивает перед
  отправкой. Баланс надёжнее узнать через SMS.
- **Бот прислал `[ "…", "…" ]`.** Стоит старый пакет бота: обновить `medvemodem-bot` и `luci-app-medvemodem-bot`.
- **Ошибка или непонятное поведение.** «Диагностика» → «Отчёт о модеме» или `medvemodem diag quick`; приложить
  `logread -e medvemodem` и `logread -e ModemManager`.
